# Lezly Therese Villanueva — Personal Portfolio

## Overview

This repository contains the source code for my personal portfolio website, built as part of my IT coursework at the University of the Immaculate Conception. The site brings together everything from my academic journey so far, including:

- **About Me** — a short introduction to who I am and what I'm currently learning.
- **Achievements & Experiences** — certificates, awards, and hands-on experiences such as my work immersion and organizational involvement.
- **Course Activities** — HTML/CSS exercises completed throughout the semester, including a restaurant landing page, a fashion blog layout, and a wine festival schedule.
- **Skills & Projects** — the tools and languages I work with, along with featured projects like *Learnly*, an HCI prototype designed for remote-community learning.

The site is built with plain **HTML** and **CSS**, and is fully responsive across desktop and mobile screens via a collapsible navigation menu.

## How to Access the Website

The portfolio is deployed live via GitHub Pages and can be viewed here:

🔗 **[https://lezlyvillanueva.github.io/](https://lezlyvillanueva.github.io/)**

### Running Locally

If you'd like to view or edit the project on your own machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/LezlyVillanueva/LezlyVillanueva.github.io.git
   ```
2. Navigate into the project folder:
   ```bash
   cd LezlyVillanueva.github.io
   ```
3. Open `index.html` in your browser (no build step or dependencies required).
